# APEX Clean Chart — выбранный сценарий, без визуального шума

Дата: 11.11.2026. Реализовано поверх `apex-synchronized-depth-20261111` в ветке `apex-clean-chart-selected-scenario-20261111`.

## Поведение

- **Первый вход на график:** ни один прогноз не выбран автоматически. Свечи, настоящий объём, структурные Order Blocks и проверенные события W доступны как прежде. Никаких полос от SL до TP3, линий Entry/SL/TP, опубликованных этапов P/1/2/4 других прогнозов в обзоре не рисуется.
- **Выбор карточки** в существующем разделе «Сценарии наблюдения на графике»: только этот сценарий появляется на графике с тонкими E/SL/T1/T2/T3, без большого сплошного прямоугольника. Линии ограничены реально закрытыми свечами и не продолжаются в ещё не наступившее время. Если тип прогноза является диапазонным, отображается тонкая фактическая полоса диапазона, не вымышленные TP/SL.
- **Повторное нажатие** на выбранную карточку и **«Скрыть уровни»** возвращают чистый график. На смене таймфрейма выбор сбрасывается; не соответствующий TF прогноз не переносится в новый период. Выбор из внешнего списка исследований сохраняет заданный ID: если пользователь намеренно открыл конкретное исследование, APEX его покажет.
- **Подробности** расположены непосредственно под графиком: исходные E, SL, TP1–TP3 и рассчитанный по исходной геометрии R:R (только при допустимой ориентации SL/TP). Никаких торговых действий; завершённый сценарий помечен как историческая запись. Порядок касаний и оценка исполнения остаются в исходном журнале.
- **Order Blocks:** исходная алгоритмика BOS/CHoCH, подтверждение, запрет заполнения пропущенных свечей и ограничения по числу зон не изменены. Заливка стала слабее; дубли близких подписей «Demand/Supply OB» объединены в «×2» (по визуальной близости), а не рисуются у каждого отдельного сегмента.
- **Whale markers:** сохранены без изменения привязки ко времени первого получения транзакции телефоном, пользовательский переключатель «W · Крупные переводы» действует как раньше.
- **Сохранённые данные:** все сценарии и этапы Room, M1-верификация, архив M5, статусы исходов, результаты и исторические свечи не модифицируются. Изменена **только презентация** поверх доказуемой исходной истории.

## Проверка CI и Android

```bash
node --test apex9-preview/test-clean-chart-scenarios.mjs
node --test apex9-preview/test-scenario-map.mjs
node --test apex9-preview/test-order-blocks-chart-stage3.mjs
node --check apex9-preview/candle-chart.mjs
node --check apex9-preview/app.mjs
node apex9-android/scripts/prepare-web.mjs --check
```

Проверка установленного APK на реальном Android:

1. Открыть избранный актив → **График** → M15 или H1. Не выбирая карточку, проверить **отсутствие** линий и кругов P/1/2/4 при сохранении свечей и Order Blocks.
2. Нажать на сохранённый сценарий ниже графика. Должна подсветиться **только одна карточка**; появятся только её соответствующие исходные уровни и компактная сводка. Вне доступного закрытого исторического интервала не дорисовывается ничего.
3. Нажать повторно либо «Скрыть уровни» — пропадают уровни и Replay курсор, а OB и W остаются.
4. Выбрать завершённый сценарий — видны его исторические уровни, состояние завершения, но не ложное текущее предложение совершить сделку.
5. Изменить таймфрейм H1 → M15 → M1, потом актив. Старые уровни не переносятся на чужой период/инструмент.
6. Проверить pinch/zoom/pan и старые экраны «Сценарии», включая точность M1-исходов. Сравнить слои OB/W до и после.
7. Если нет проверенного Room-источника, виден корректный текст, не подставляются фальшивые сценарии.

Сборка GitHub CI не заменяет визуальную приёмку и ресурсное измерение на физическом телефоне.

**Граница:** PR основан на предшествующих исследовательских ветках. Без последующего объединения всех PR с основной веткой `main` эти изменения не являются официальным выпуском APEX.
