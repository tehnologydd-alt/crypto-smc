# APEX 9 — шесть бирж, крупные сделки и исследование возможных взаимосвязей

## Источники и условия
- Binance Spot: `aggTrade`, отдельная имеющаяся реализация.
- Bybit Spot: публичный `publicTrade.<SYMBOL>`, taker `S`.
- OKX Spot: публичный канал `trades`, taker `side`.
- Kraken Spot: WebSocket v2 `trade`, taker `side`.
- BingX Spot: `<BASE>-USDT@trade`, публичные **GZIP**-сообщения; необходим поддерживаемый декодер `DecompressionStream` в WebView. Если отсутствует — статус недоступности, а не выдуманные сделки.
- Coinbase **Exchange**: `matches`, продукт `<BASE>-USD`; поле `side` задаёт **maker**, поэтому taker противоположен. В отличие от остальных Coinbase использует USD, не USDT — эти денежные суммы не складываются как одна валюта.

Все используют публичную торговую ленту без клиентского API-ключа; подтверждение фактической доступности каждого источника возможно только после теста на устройстве. Некоторые активы могут не существовать в Spot на конкретной бирже. Подписывается только один открытый избранный актив; при сворачивании потоки закрываются. Источники хранятся независимо, не синхронизируются искусственно и не пересчитываются под одну «китовую транзакцию».

## Объединение исследований
Поиск `≥150 000` единиц **котируемой валюты** на одно наблюдаемое биржевое исполнение, с фильтрами 500 тыс./1 млн, сохранением точного ID и источника в локальную Room. Одна агрегированная сделка Binance и отдельный fill Bybit / OKX / Kraken / BingX / Coinbase **разные единицы наблюдения**. Простой подсчёт по биржам не означает сравнимую торговую интенсивность.

Сопоставление: группы крупных наблюдений **разных бирж** в пределах 60 секунд, а для BTC/ETH отдельно близкие ±5 минут **публичные ончейн-наблюдения** из существующего, ограниченного архива телефона. Метки имеют состояния `TEMPORAL_COINCIDENCE_ONLY` и `TIME_PROXIMITY_ONLY`. Никакой модели идентификации владельцев, маршрута средств, депозитов на биржу, намерения или причинности здесь **нет**.

Нельзя однозначно вывести «кто перевёл кому» из WebSocket публичных торгов: биржа не публикует такие данные в `trade` / `match`. При наличии независимо проверенных меток кошельков и идентификаторов переводов можно исследовать больше, но не задним числом доказывать личность из совпавшего объёма.

## Ограничения нагрузки и риска
- Один актив, максимум пять дополнительных соединений и существующий Binance, только вкладка «Данные» при открытом Android.
- Отдельное ограничение до 60 событий в минуту **на источник**, старые ID не перезаписываются. При сильном потоке выборка неполная; нет сканирования всех активов.
- Без демоданных, аккаунтов, приватных запросов, торговых приказов или утверждений о достоверности будущей реакции цены.
- Для BingX поток требует поддержки GZIP средствами WebView. Специфика heartbeat и выбор доступных Spot-пар зависят от API биржи.
- Корреляция без независимой проверки последующих движений цены не даёт прогностическую ценность.
