# Crypto SMC

Android-приложение для анализа криптовалют: избранные активы, Smart Money Concepts (ордер-блоки, структура, ликвидность), сентимент и мульти-AI консенсус.

## Статус

- [x] Этап 1: каркас, настройки, реестр AI-провайдеров, сборка APK через GitHub Actions
- [x] Этап 2: избранное (поиск пар Binance, цены и изменение за 24 ч)
- [x] Этап 3: рыночные данные (свечи 15m/1h/4h/1d с кэшем, стакан, funding, open interest, экран актива)
- [x] Этап 4: детерминированный SMC-движок (свинги, BOS/CHoCH, FVG, ордер-блоки, premium/discount, equal highs/lows)
- [ ] Этап 5: волатильность и карта ликвидности
- [ ] Этап 6: сентимент
- [ ] Этап 7: AI-консенсус
- [ ] Этап 8: журнал прогнозов
- [ ] Этап 9: алерты

## Сборка

Каждый push в `main` запускает GitHub Actions. APK лежит в Actions, в артефакте `crypto-smc-debug`.

## AI-провайдеры

Все провайдеры работают через OpenAI-совместимый формат `/chat/completions`. Добавлять, менять и отключать их можно в приложении (вкладка «Настройки»). API-ключи хранятся в зашифрованном хранилище устройства и в код не попадают.
