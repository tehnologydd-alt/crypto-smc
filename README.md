# Market Intelligence AI

Нативное Android-приложение на Kotlin для исследовательского анализа крипторынка. Источник рыночных данных — публичный Binance API. Все сделки виртуальные: ключи биржи и отправка реальных ордеров не используются.

## Экраны

| Вкладка | Что внутри |
|---|---|
| Рынок | Избранные пары, цены, изменение за 24 ч, объём, сортировка, экран актива (график с зумом, SMC-зоны, стакан, фьючерсы, сентимент) |
| Анализ | Выбор пары, SMC, волатильность, сентимент, мульти-AI консенсус, R:R, переход в виртуальную сделку с уровнями AI |
| Журнал | Все AI-прогнозы, проверка через 1/4/24 ч, точность консенсуса и моделей, калибровка уверенности |
| Сделки | Виртуальный счёт, BUY/SELL, SL/TP, живой P/L, несколько пар одновременно, сброс счёта |
| Ещё | AI-провайдеры и промпт, источники данных (токен CryptoPanic), алерты, Android-уведомления, Telegram |

## Архитектура

```
app/src/main/java/com/cryptosmc/app/
├── ai/          провайдеры, OpenAI-compatible клиент, консенсус
├── alerts/      правила алертов, фоновая проверка, уведомления, Telegram
├── journal/     журнал прогнозов и статистика
├── market/      Binance API, кэш, избранное
├── sentiment/   агрегатор сентимента
├── settings/    зашифрованное хранилище токенов
├── smc/         SMC-движок и историческая проверка
├── trading/     виртуальный счёт
├── volatility/  ATR, ликвидность
└── ui/          тема, компоненты, экраны, навигация
```

Дизайн-система: `ui/Theme.kt` (палитра, типографика, формы), `ui/Components.kt` (карточки, плитки, чипы, сворачиваемые секции). Экраны собираются только из этих компонентов, цвета заданы в одном месте.

## Известные особенности

- `VirtualTradingRepository.processCandles(candles)` применяет свечи ко всем открытым позициям независимо от пары. Для нескольких пар используй `processCandlesFor(symbol, candles)` (`trading/SymbolCandleProcessor.kt`).
- `AlertEngine.evaluate` (старый) срабатывает на структуру постоянно, если событие существует. Актуальная логика в `AlertChecker` (`alerts/AlertRunner.kt`) реагирует только на новое событие.
- Фоновые задачи Android могут задерживаться в режиме экономии заряда.

## Сборка APK

GitHub Actions собирает debug-APK при push и pull request в `main` после unit-тестов. APK лежит в артефактах запуска Build APK. Локально: Android Studio, JDK 17.

## Важные ограничения

- SMC-разметка — алгоритмическая эвристика, а не подтверждённая интерпретация институциональных ордеров.
- Сентимент по заголовкам — простая эвристика по словам, не NLP.
- AI consensus — исследовательское агрегирование. Confidence не является калиброванной вероятностью.
- SL/TP симулятора проверяются по OHLC-свечам. Если одна свеча затронула SL и TP, применяется SL.
- Никакой реальной торговли нет. Не добавляй биржевые секреты в исходный код или Git.
