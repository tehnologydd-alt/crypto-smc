# Market Intelligence AI

Нативное Android-приложение на Kotlin для исследовательского анализа крипторынка. Первый источник рыночных данных — публичный Binance API. Все сделки в текущей версии виртуальные: ключи биржи и отправка реальных ордеров не используются.

## Архитектура и текущий статус

- [x] Android / Kotlin / Jetpack Compose, отдельные модули данных, аналитики и UI.
- [x] Избранные пары Binance: поиск, цены и изменение за 24 часа.
- [x] Рыночные данные: свечи, кэш, стакан, funding и open interest.
- [x] SMC-ядро: swing points, BOS/CHoCH, FVG, эвристические order blocks, premium/discount и равные максимумы/минимумы.
- [x] Волатильность: ATR и реализованная волатильность.
- [x] Карта ликвидности на основе доступных уровней стакана и open interest.
- [x] Сентимент: Fear & Greed, Reddit и CryptoPanic (последний требует токен).
- [x] Настраиваемые OpenAI-compatible AI-провайдеры; ключи хранятся в зашифрованном хранилище устройства.
- [x] Экран Market Intelligence: локальные рыночные признаки и мульти-AI консенсус.
- [x] Виртуальный счёт: пополнение, BUY/SELL, резервирование номинала, комиссии, SL/TP, история и сохранение.
- [ ] Проверка качества прогнозов на исторических данных и калибровка уверенности.
- [ ] Полная интеграция журнала прогнозов и алертов в пользовательский интерфейс.
- [ ] Уведомления Android и Telegram.
- [ ] Интерактивный график с отображением виртуальных сделок, SL/TP и зон SMC.
- [ ] Автоматизированные unit/instrumentation tests и подтверждённая сборка APK.

## Сборка APK

Открой репозиторий в Android Studio, используй JDK 17 и дождись Gradle Sync. Для локальной сборки выбери Build → Build Bundle(s) / APK(s) → Build APK(s).

GitHub Actions также запускает debug-сборку при pull request в main. APK должен появиться в артефактах успешного запуска workflow Build APK.

## AI-провайдеры

Провайдеры используют OpenAI-совместимый endpoint /chat/completions. Вкладка «Настройки» позволяет добавлять endpoint, модель, ключ и вес провайдера. У разных провайдеров могут меняться бесплатные лимиты и доступность моделей.

## Важные ограничения

- SMC-разметка — алгоритмическая эвристика, а не подтверждённая интерпретация институциональных ордеров.
- Сентимент по заголовкам Reddit — упрощённая эвристика, не полноценная NLP-классификация.
- AI consensus — исследовательское агрегирование ответов. Confidence не является статистически калиброванной вероятностью.
- SL/TP симулятора проверяются по OHLC-свечам. Если одна свеча затронула и SL, и TP, применяется консервативное допущение SL первым.
- Никакой реальной торговли нет. Не добавляй биржевые секреты в исходный код или Git.
