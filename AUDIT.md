# Аудит исходного архива и сделанные изменения

Источник: `apexicrypto-smc-&-whale-intelligence.zip`.

| Проверка | В исходном проекте | В автономной версии |
|---|---|---|
| Запуск | `tsx server.ts` под Node.js/Express, `/api/*` | `vite` для разработки, HTML/JS/CSS упаковываются внутрь Android APK с Capacitor |
| AI Studio | `APP_URL`, Cloud Run fallback, README-ссылка на AI Studio | Ни одной ссылки на hosting runtime; `server.url` отсутствует |
| ИИ | `@google/genai` и `GEMINI_API_KEY`, fallback с фиксированными 86% | Локальный проверяемый анализ трёх правил, без облачных LLM и процентов выигрыша |
| Биржевые данные | Получались через Express, при ошибках подставлялись цены BTC 68450 и др. | Публичные HTTPS API с телефона; недоступные котировки не подделываются |
| Киты | Семь статических «транзакций» с динамическим временем и заданными компаниями | Настоящие видимые заявки из публичных стаканов. Ончейн-мониторинг **не реализован** |
| Соцсети | Прописанные в коде 64% позитива и фиктивная `CryptoBERT` | Fear & Greed из публичного источника + движение биржевой цены; данные соцсетей не выдумываются |
| Работа без интернета | Service worker кешировал UI, но API недоступен | В APK интерфейс локальный, сохранённый последний срез помечен как устаревший, новые рыночные данные требуют сети |
| APK | Кнопка в интерфейсе ведёт к PWA Builder / стороннему сайту | Android/Capacitor, готовый скрипт Windows и GitHub Actions для создания debug APK |

## Проверено здесь

- Синтаксис 19 файлов TypeScript/TSX: без ошибок парсинга.
- Интеграционный тест `npm test` на тестовых (помеченных как тестовые) ответах API: биржевые цены, расчёт SMC, заявки, локальная аналитика, Fear & Greed, отказ от фальшивых цен без сети: успешно.
- Сборка `npm run build` и Android APK в этом контейнере не запускались: нет доступного npm registry и установленного Android SDK. Поэтому реальную сборку APK и работу на телефоне требуется проверить через включённый GitHub Actions или Android Studio.
