Android First

APEX самостоятельно исследует сохранённые активы, формирует сценарии по завершённым H1-свечам и наблюдает за результатами. Пользователю не нужно создавать прогнозы вручную.

Сейчас используется проверяемая базовая гипотеза ценового диапазона. Статус «Подтверждён» означает техническую проверку первой последующей свечи, не доказанную точность прогноза. При отсутствии данных вывод не выдумывается.
